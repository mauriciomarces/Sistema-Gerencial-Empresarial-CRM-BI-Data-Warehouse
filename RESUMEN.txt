📊 FLUJO DE DATOS
═══════════════════════════════════════════════════════════════════════════════

MAÑANA:
─────
Usuario crea Orden de Venta en Odoo
         ↓
PostgreSQL guarda la orden (OLTP)
         ↓
Redis cachea la sesión
         ↓
Navegador muestra confirmación

CADA HORA (Automático):
───────────────────
ETL Service se ejecuta
         ↓
Conecta a Odoo API (XML-RPC)
         ↓
Lee cambios últimos 60 minutos
         ↓
Transforma datos (normalización)
         ↓
Inserta en SQL Server DW (OLAP)
         ↓
Registra logs de éxito/error
         ↓
Próxima ejecución en 1 hora

  $ docker-compose logs -f odoo

  $ docker-compose exec etl-service python etl_nestle.py

  $ docker stats
